# סידור יומי

סידור בנוסח עדות המזרח (טקסט: Sefaria, Siddur Edot HaMizrach, Shaliehsaboo Edition)
שמתאים את עצמו לתאריך העברי ולזמני היום בעיר שנבחרה (ברירת מחדל: רמלה). עובד בלי אינטרנט ובלי בקשות לשרתים אחרים.

מדיניות פרטיות: privacy.html · חומרי חנות ושלבים הבאים: store/NEXT_STEPS.md

## העלאה ל-GitHub Pages
1. יוצרים repository חדש (למשל siddur) ומעלים את כל הקבצים שבתיקייה הזו לשורש שלו.
2. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
3. אחרי דקה-שתיים האתר זמין בכתובת https://<user>.github.io/siddur/
4. בטלפון: פותחים את הכתובת ב-Chrome → תפריט → "הוספה למסך הבית".

## עדכון גרסה
כשמחליפים קובץ כלשהו, משנים את VERSION בקובץ sw.js (למשל siddur-v3) כדי שהטלפון יטען את הגרסה החדשה.
